# Fuentes: el puntito verde del celular

- iPhone: el indicador verde = una app usa la cámara (o cámara y micrófono); el naranja = el micrófono. Apple — https://support.apple.com/108331
- iPhone: en el Centro de control sale el nombre de la app que usa la cámara o el micrófono. MacRumors — https://www.macrumors.com/how-to/when-app-uses-iphone-camera-microphone/ ; Reader's Digest — https://www.rd.com/?p=1579537
- Android 12+: indicadores verdes arriba a la derecha cuando se usan cámara o micrófono; deben mostrar el nombre de la app. Android Open Source Project — https://source.android.com/docs/core/permissions/privacy-indicators
- Android: en Ajustes rápidos se toca el icono para ver qué app lo usa. Android Developers — https://developer.android.com/training/permissions/explaining-access
